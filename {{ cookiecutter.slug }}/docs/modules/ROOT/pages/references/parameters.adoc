= Parameters

The parent key for all of the following parameters is `{{ cookiecutter.parameter_key }}`.

== `namespace`

[horizontal]
type:: string
default:: `syn-{{ cookiecutter.slug }}`

The namespace in which to deploy this component.

== `createNamespace`

[horizontal]
type:: boolean
default:: `true`

Whether to create the namespace.

== `namespaceLabels`

[horizontal]
type:: dict
default:: `{}`

Labels to add to the namespace.

== `namespaceAnnotations`

[horizontal]
type:: dict
default:: `{}`

Annotations to add to the namespace.

== Example

[source,yaml]
----
namespace: example-namespace
createNamespace: true
namespaceLabels:
  example.com/label: value
namespaceAnnotations:
  example.com/annotation: value
----
